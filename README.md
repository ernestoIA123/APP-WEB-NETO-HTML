# Neto HTML

Editor HTML con vista previa funcional, actualización en tiempo real y edición visual directa.

## Funciones principales

- Buscador verde con contador y navegación entre coincidencias.
- Enlaces destacados en azul dentro del código.
- Vista previa arriba en teléfonos y tablets.
- Doble clic sobre un texto de la vista previa para editarlo.
- Doble clic sobre una imagen para cambiar su enlace de Cloudinary o URL.
- Modo visual por defecto y botón morado **Modo Pro** para mostrar código + resultado.
- Menú para abrir o editar el enlace de cualquier botón de la página.
- Botón **Agregar código** para cargar una página HTML completa.

## Abrir en VS Code

1. Descomprime la carpeta.
2. Ábrela en Visual Studio Code.
3. Abre `index.html` con Live Server o directamente en tu navegador.

## Subir a GitHub y Vercel

1. Crea un repositorio nuevo en GitHub.
2. Sube todos los archivos de esta carpeta.
3. En Vercel, elige **Add New > Project** e importa el repositorio.
4. Deja **Framework Preset** en **Other** y pulsa **Deploy**.

No necesita instalar dependencias ni ejecutar comandos de compilación.
